# Vocabularfy 🇭🇺

A Vocabularfy egy modern, reszponzív, önálló HTML fájlban futtatható szókincsfejlesztő webalkalmazás, amely segít hatékonyan elsajátítani az új angol kifejezéseket. Használata egyszerű: nincs szükség külső szerverre vagy bonyolult telepítésre, csak egy böngészőre és minimális internetkapcsolatra, és máris kezdődhet a gyakorlás!

---

## 🚀 Főbb funkciók

* **5 Különböző Gyakorlási Mód:** Válaszd ki a számodra leginkább szimpatikus tanulási módszert.
* **Kétirányú Fordítás:** Gyakorolhatsz Angol ➔ Magyar, valamint Magyar ➔ Angol irányban is.
* **Rugalmas Körök:** Határozd meg, hány szót szeretnél gyakorolni egy alkalommal (5, 10, 20, 50, 100 vagy akár az összes szó).
* **Napi Sorozat (Streak) Követés:** Motivációs rendszer, amely figyeli a napi gyakorlási sorozatodat.
* **Hangalapú Kiejtés (Text-to-Speech):** Hallgasd meg az angol kifejezések helyes kiejtését a beépített böngészős beszéd szintetizátor segítségével.
* **Sötét / Világos Mód:** Szemkímélő sötét mód támogatás automatikus rendszerpreferencia-detektálással és kézi kapcsolóval.
* **Saját Szókincs & Adatkezelés:** 
  * Bővítsd a szótárat saját szavakkal.
  * Exportáld és importáld a szótáradat JSON formátumban.
* **Rontott Szavak Újragyakorlása:** A kör végén lehetőség nyílik kizárólag a hibásan megválaszolt kifejezések átismétlésére.

---

## 🎮 Gyakorlási módok részletesen

1. **Feleletválasztó (Quiz):** 4 lehetséges opció közül kell kiválasztani a helyes magyar vagy angol jelentést.
2. **Gépelés (Type):** Aktív szövegbeviteli mezőbe kell leírni a helyes fordítást, ami ellenőrzi a pontosságot.
3. **Kártya (Flashcard):** 3D-s animációval megfordítható tanulókártyák ("Tudtam" / "Nem tudtam" értékeléssel).
4. **Igaz / Hamis (True / False):** El kell dönteni egy adott szó-párosításról, hogy a helyes jelentést mutatja-e.
5. **Párosító (Matching Game):** Interaktív rács, ahol össze kell kötni a szavakat a megfelelő jelentéseikkel.

---

## 🛠️ Használt web technológiák

* **HTML5 & Vanilla JavaScript (ES6+)** – Az üzleti logika és az interaktív felületek kezelése.
* **Tailwind CSS** – Gyors, reszponzív és modern dizájn keretrendszer CDN-en keresztül.
* **Font Awesome (v6.0)** – Ikonok a vizuális visszajelzésekhez és gombokhoz.
* **Web Speech API** – A natív böngészős kiejtés-támogatáshoz.
* **LocalStorage API** – A beállítások, a sötét mód, a napi streak és a saját szavak helyi mentéséhez.

# Vocabularfy 🇬🇧

Vocabularfy is a modern, responsive English-Hungarian and Hungarian-English vocabulary practice web app featuring 5 learning modes, text-to-speech pronunciation, and streak tracking. It runs entirely as a single HTML file—no external server or complex installation is required; just open it in your browser and start learning!

---

## 🚀 Key Features

* **5 Different Practice Modes:** Choose the learning method that suits you best.
* **Two-Way Translation:** Practice English ➔ Hungarian as well as Hungarian ➔ English.
* **Flexible Rounds:** Select how many words you want to practice per session (5, 10, 20, 50, 100, or all words).
* **Daily Streak Tracking:** A built-in motivational system to keep track of your daily practice habits.
* **Text-to-Speech Pronunciation:** Listen to the correct pronunciation of English expressions using the browser's native speech synthesis.
* **Dark / Light Mode:** Eye-friendly dark mode support with automatic system preference detection and a manual toggle.
* **Custom Vocabulary & Data Management:** 
  * Add your own words to the dictionary.
  * Export and import your vocabulary database using JSON format.
* **Mistake Review:** Option to re-practice only the incorrectly answered terms at the end of a round.

---

## 🎮 Practice Modes Explained

1. **Quiz:** Choose the correct translation from 4 multiple-choice options.
2. **Type:** Type the correct translation into an active input field for precise validation.
3. **Flashcard:** Interactive 3D flip cards evaluated with "Knew" / "Did not know" buttons.
4. **True / False:** Decide whether a given word pair matches correctly.
5. **Matching Game:** An interactive grid to pair terms with their correct definitions.

---

## 🛠️ Web technologies used

* **HTML5 & Vanilla JavaScript (ES6+)** – Core logic and interactive interface.
* **Tailwind CSS** – Modern, responsive design framework via CDN.
* **Font Awesome (v6.0)** – Visual icons and feedback buttons.
* **Web Speech API** – Native browser-based pronunciation support.
* **LocalStorage API** – Persistent local storage for settings, dark mode, streaks, and custom words.

---

## 🚀 Running Locally

1. Clone or download the repository.
2. Open the main HTML file `vocabularfy.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
